# Stage 2 additions (to be placed next to the main package)
- `data/test.jsonl`, `data/raw_test.jsonl`: the third document split (39 articles) of the same Wikipedia prefix, for archive. Sizes 571,333 and 573,860 bytes. Not used for selection, tuning or any reported number; no model was evaluated on it. The relation to train/val: each article is assigned to exactly one split by a hash of its page id (checked on the 398 articles listed in `data/manifest.jsonl`; subset rule in `prep2_report.json`); paragraph overlap with train was measured (`overlap_hist`), which does not prove absence of leakage. Their sha256 are in `data/prep2_report.json`. Same license and attribution as the other data files.
- `source/prefix16MB.bz2`: the first 16,000,000 bytes of the Spanish Wikipedia dump file named in `data/LICENSE_SOURCE.json` (sha256 283f710e07a46b513cf197ddcc926e1c0138a117acc5af6fa67a19c1301847aa). This is an incomplete bz2 stream (a byte prefix), so a bz2 reader reports an unexpected end of file after the data it can read. Same license and attribution.
- `es3/`: see `es3/README.md`.
Omitted on purpose: the 3-step continuity-test checkpoints (only `results/t0_res.json` is kept), ES4 generations g001-g074.

Note on `source/prefix16MB.bz2`: it is a byte prefix of a public Wikimedia dump and, like the dump, contains the usernames or IP addresses of Wikipedia contributors in page revision metadata. These are public identifiers of the source, not private data of the authors of this archive. The file is kept exactly as downloaded so that the data preparation stays reproducible; it was not edited.
