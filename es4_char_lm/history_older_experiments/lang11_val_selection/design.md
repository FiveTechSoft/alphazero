# lang11: practice chosen from validation failures vs uniform vs shuffled

Design reconstructed retrospectively from the original run records (design notes, code, results). It is a restatement written after the runs, not a contemporaneous pre-registration. Results are in results/. All tasks are small synthetic in-context binding tasks (word -> colour -> cell); none is about natural language, speech, or self-improvement.

Question: does a loop that weights training contexts by its own validation errors (A) beat equal-cost uniform practice (U) and equal-cost failure-agnostic reweighting (S) on genuinely new association combinations?
Family: 6 words, 6 colours, 5400 contexts (15 word sets x 360 injective colour maps). 90 of 450 association pairs are withheld (45 for validation, 45 for test) with partition seed 20261025. Pool = 1351 contexts with no withheld pair; val = 1482; test = 1500 (sealed).
Training: 5000 updates x batch 32, seeds 21, 22, arms A, U, S, same init; weights recomputed every 500 updates from 1200 validation prompts (clip ratio 10, eps 0.05); S uses the same formula with the error vector permuted.
Outcome on validation (selection set only, final exact match on 1200 val prompts): seed 21: A 0.112, U 0.086, S 0.086; seed 22: A 0.270, U 0.063, S 0.243. In seed 22 the shuffled-weights arm S is close to A, so the A advantage over S is not shown there on validation. Effective-sample-size ratio of the A weights stayed between 0.96 and 1.0 (weights were close to uniform). One run per cell, two seeds, no variance estimate.
The sealed test set is not archived and was not read here; only its hash and construction rule are in manifest11.json. The test evaluation of these final weights is archived separately and is not part of this folder.
The validation prompts and the association permutations used by S were generated by a separate script (not included); the files themselves are included as inputs.
