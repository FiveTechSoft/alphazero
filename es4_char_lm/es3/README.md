# ES3: 200-step run of the same character LM (earlier, shorter run)

Same architecture, data and fixed evaluation windows as the main package (6 layers, d=256, 4 heads, context 256, 4,842,496 parameters, batch 2 windows of 256 characters). One run, seed 14014, 200 steps, 20 warmup steps, constant learning rate 1e-3, AdamW. Mean validation cross-entropy fell from 5.0898 (initial weights) to 2.5034 on the fixed 64 validation windows (28 articles). Compared with character n-gram baselines on the same windows: the final model is better than the unigram table (difference -0.578 nats per character, window mean) and WORSE than the bigram table on these fixed windows (+0.092, all 28 articles positive; article-grouped SE 0.005). `res.json` has the full record (losses, baselines on the same windows, document-grouped differences with n=28 articles, reload check).
Limits: one seed; short run; windows from few articles; not speech, not conversation, not self-improvement.

Files: `init.pt` (initial weights), `final.pt` (weights after 200 steps; sha256 79186c21af2063ccd84e967af23ed39792fc4328cf7013a8f43753f256e473ce), `adam.pt.part00/.part01` (AdamW state; join with `cat adam.pt.part00 adam.pt.part01 > adam.pt`, sha256 of the joined file e2c943c448265691...; full value in the manifest), `train_rng_es3.npz` (numpy and torch RNG states at the end, plain arrays, load with `allow_pickle=False`), `res.json`.
The weight files load with `torch.load(..., weights_only=True)`. Evaluation code is `code/es4_torch.py` in the main package (same model class). This ES3 package has not been reloaded or re-evaluated from this export.
